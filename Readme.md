# 📦 Anomaly Detection & Object Recognition in Logistic Environments

This repository showcases a collection of Python scripts and code snippets I developed during my master's studies as a Student Research Assistant at the Chair of Data Science and Data Engineering (LS-9), TU Dortmund University.

The work involved close collaboration with PhD students on research topics related to:
- ✅ **Detecting anomalies** in visual data using image reconstruction and similarity analysis
- ✅ **Re-identifying pallet blocks** in a logistics setting
- ✅ **Object detection** in complex warehouse environments

---

## 🧠 Project Focus

### 1. 🔍 Anomaly Detection & Re-identification with Autoencoders

- **Objective:** Reconstruct pallet block images and identify anomalies by analyzing differences.
- **Technique:**
  - **Autoencoder-based reconstruction**
  - **SSIM (Structural Similarity Index Measure)** used to compare original and reconstructed images
- **Application:** Helps detect damaged or irregular pallet blocks automatically.

### 2. 📦 Object Detection in Logistic Workspaces

- **Objective:** Automatically detect and classify objects in logistic scenes (e.g., warehouses).
- **Technique:**
  - Implemented object detection models like **YOLO** or **Faster R-CNN**
  - Dataset annotation and training for real-world warehouse layouts
- **Application:** Supports automation in logistics—item recognition, inventory monitoring, and quality assurance.
